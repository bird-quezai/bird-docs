version-update 版本更新

提供页面版本自动检测功能，通过比较页面 HTML 内容判断是否有更新，并提示用户刷新页面。

基础用法 ​

ts
import { versionUpdate } from '@bird/utils'

// 启动版本更新检测
versionUpdate()

工作原理 ​

  1. 获取当前页面的 HTML 内容
  2. 定期获取服务器最新的 HTML 内容（带时间戳避免缓存）
  3. 比较 <script> 标签的 src 属性是否有变化
  4. 检测到更新时显示提示框，5 秒后自动刷新

自动更新提示 ​

当检测到更新时，页面会显示一个提示框：

提示
系统检测到您当前版本还处于旧版本状态，为了让您有更好的用户体验，
系统将在 5 秒钟之后进行刷新.....
[确定]

用户可以：

  • 点击"确定"按钮立即刷新
  • 等待 5 秒后自动刷新

页面可见性检测 ​

组件会监听页面可见性状态（visibilitychange 事件），只有当页面可见时才会进行版本检测，避免在后台标签页进行无意义的检测。

ts
document.addEventListener('visibilitychange', () => {
  // 只有页面可见时才会检测版本
  if (document.visibilityState === 'visible') {
    // 执行版本检测
  }
})

API ​

versionUpdate() ​

检测页面版本是否更新，如果有更新则提示用户并自动刷新页面。

返回值： Promise<void>

说明：

  • 异步操作，检测到更新后会显示提示
  • 默认在 5 秒后自动刷新
  • 用户可以点击"确定"按钮立即刷新
ts
import { versionUpdate } from '@bird/utils'

// 基本用法
versionUpdate()

// 带错误处理
versionUpdate().catch(error => {
  console.error('版本检测失败:', error)
})

配置说明 ​

配置项默认值说明
UPDATE_AFTER_MS5000检测到更新后等待刷新的时间（毫秒）

实际应用示例 ​

在应用入口启动检测 ​

ts
// main.ts
import { createApp } from 'vue'
import { versionUpdate } from '@bird/utils'
import App from './App.vue'

const app = createApp(App)
app.mount('#app')

// 启动版本检测
versionUpdate()

在布局组件中使用 ​

vue
<template>
  <router-view />
</template>

<script setup lang="ts">
import { onMounted } from 'vue'
import { versionUpdate } from '@bird/utils'

onMounted(() => {
  // 组件挂载后启动版本检测
  versionUpdate()
})
</script>

注意事项 ​

  1. 仅检测 script 标签：版本检测通过比较 <script> 标签的 src 属性，不会检测 CSS 或其他资源
  2. 需要网络请求：会向当前页面 URL 发送带时间戳的请求获取最新 HTML
  3. 移动端适配：提示框会根据移动端/PC 端调整样式
  4. 单次检测：检测到更新后只会提示一次，不会重复检测

检测流程 ​

开始
  ↓
获取当前页面 HTML
  ↓
获取最新页面 HTML（带时间戳）
  ↓
比较 script 标签 src 属性
  ↓
相同 ──→ 等待页面可见 ──→ 继续检测
  ↓
不同
  ↓
显示提示框
  ↓
倒计时 5 秒
  ↓
刷新页面

// 源码中的 hintDiv.innerHTML 部分可以根据需求修改

替代方案 ​

如果需要更精细的控制，可以考虑以下替代方案：

  1. 使用 PWA：通过 Service Worker 实现更完善的版本管理
  2. API 版本检测：通过后端 API 返回版本号进行比对
  3. WebSocket 通知：后端推送版本更新通知
