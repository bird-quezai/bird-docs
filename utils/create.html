createNameSpace 命名空间生成

用于生成 BEM（Block Element Modifier）格式的 CSS 类名，常用于组件库开发。

基础用法 ​

ts
import { createNameSpace } from '@bird/utils'

const bem = createNameSpace('button')

// 生成块级类名
bem.b('box') 
// 输出：'bi-button-box'

// 生成元素类名
bem.e('icon')
// 输出：'__icon'

// 生成修饰符类名
bem.m('disabled')
// 输出：'--disabled'

// 生成块 + 元素类名
bem.be('box', 'icon')
// 输出：'bi-button-box__icon'

// 生成块 + 修饰符类名
bem.bm('box', 'disabled')
// 输出：'bi-button-box--disabled'

// 生成元素 + 修饰符类名
bem.em('icon', 'disabled')
// 输出：'__icon--disabled'

// 生成完整类名
bem.bem('box', 'icon', 'disabled')
// 输出：'bi-button-box__icon--disabled'

// 生成状态类名
bem.is('checked', true)
// 输出：'is-checked'

bem.is('checked', false)
// 输出：''

在 Vue 组件中使用 ​

vue
<template>
  <div :class="[bem.b('')]">
    <span :class="[bem.e('icon')]">图标</span>
    <span :class="[bem.e('text')]">文本</span>
  </div>
</template>

<script setup lang="ts">
import { createNameSpace } from '@bird/utils'

const bem = createNameSpace('button')
</script>

<style scoped>
.bi-button {
  display: inline-flex;
  align-items: center;
}

.bi-button__icon {
  margin-right: 8px;
}

.bi-button--disabled {
  opacity: 0.5;
  cursor: not-allowed;
}

.is-checked {
  color: #409EFF;
}
</style>

返回值说明 ​

方法参数说明示例
bblock: string生成块级类名bem.b('box') → 'bi-name-box'
eelement: string生成元素类名bem.e('icon') → '__icon'
mmodifier: string生成修饰符类名bem.m('disabled') → '--disabled'
beblock: string, element: string生成块 + 元素类名bem.be('box', 'icon') → 'bi-name-box__icon'
bmblock: string, modifier: string生成块 + 修饰符类名bem.bm('box', 'disabled') → 'bi-name-box--disabled'
emelement: string, modifier: string生成元素 + 修饰符类名bem.em('icon', 'disabled') → '__icon--disabled'
bemblock: string, element: string, modifier: string生成完整类名bem.bem('box', 'icon', 'disabled') → 'bi-name-box__icon--disabled'
isname: string, state: boolean生成状态类名bem.is('checked', true) → 'is-checked'

BEM 命名规范 ​

BEM 是一种 CSS 命名方法论，包含三个部分：

  • Block（块）：独立的实体，如 button、input
  • Element（元素）：块的组成部分，如 button__icon
  • Modifier（修饰符）：块或元素的状态或变体，如 button--disabled

最佳实践 ​

  1. 使用有意义的命名：类名应该清晰表达其用途
  2. 避免嵌套过深：BEM 旨在扁平化 CSS 结构
  3. 保持一致性：在整个项目中遵循相同的命名约定
ts
// 好的命名
const bem = createNameSpace('user-card')
bem.b('') // 'bi-user-card'
bem.e('avatar') // '__avatar'
bem.e('name') // '__name'

// 避免使用缩写
const bem = createNameSpace('uc') // 不推荐
