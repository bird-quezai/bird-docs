url URL 工具

提供 URL 处理相关的实用功能，包括参数解析、查询字符串构建、参数移除等。

基础用法 ​

ts
import { getUrlParams, qsStringify, removeUrlParams } from '@bird/utils'

// 获取 URL 参数
const params = getUrlParams('https://example.com?a=1&b=2')
// { a: '1', b: '2' }

// 对象转查询字符串
const query = qsStringify({ name: 'John', age: 30 })
// 'name=John&age=30'

// 移除 URL 参数
const newUrl = removeUrlParams('https://example.com?a=1&b=2', 'a')
// 'https://example.com?b=2'

URL 参数解析 ​

ts
import { getUrlParams } from '@bird/utils'

// 完整 URL
const params1 = getUrlParams('https://example.com/page?userId=123&token=abc')
// { userId: '123', token: 'abc' }

// 仅查询字符串
const params2 = getUrlParams('?name=John&city=Beijing')
// { name: 'John', city: 'Beijing' }

对象转查询字符串 ​

ts
import { qsStringify } from '@bird/utils'

// 基本用法
qsStringify({ name: 'John', age: 30 })
// 'name=John&age=30'

// 包含空格
qsStringify({ q: 'hello world' })
// 'q=hello+world'

// 不编码空格为加号
qsStringify({ q: 'hello world' }, false)
// 'q=hello%20world'

// 过滤 null 和 undefined
qsStringify({ name: 'John', extra: null, unused: undefined })
// 'name=John'

移除 URL 参数 ​

ts
import { removeUrlParams } from '@bird/utils'

const url = 'https://example.com/page?a=1&b=2&c=3'

// 移除单个参数
removeUrlParams(url, 'b')
// 'https://example.com/page?a=1&c=3'

// 移除多个参数
removeUrlParams(url, ['a', 'c'])
// 'https://example.com/page?b=2'

// 移除所有参数
removeUrlParams(url, ['a', 'b', 'c'])
// 'https://example.com/page'

API ​

getUrlParams(url) ​

从 URL 中提取参数。

参数类型说明
urlstring需要解析的 URL

返回值： Record<string, string> - 参数对象

ts
getUrlParams('https://example.com?a=1&b=2&c=3')
// { a: '1', b: '2', c: '3' }

qsStringify(obj, shouldEncodeSpaceAsPlus) ​

将对象转换为查询字符串。

参数类型默认值说明
objRecord<string, any>-需要转换的对象
shouldEncodeSpaceAsPlusbooleantrue是否将空格编码为加号

返回值： string - 查询字符串

ts
qsStringify({ name: 'John Doe', age: 30 })
// 'name=John+Doe&age=30'

qsStringify({ name: 'John Doe', age: 30 }, false)
// 'name=John%20Doe&age=30'

removeUrlParams(url, params) ​

从 URL 中移除指定参数。

参数类型说明
urlstring原始 URL
paramsstring | string[]需要移除的参数名

返回值： string - 移除参数后的 URL

ts
removeUrlParams('https://example.com?a=1&b=2', 'a')
// 'https://example.com?b=2'

removeUrlParams('https://example.com?a=1&b=2&c=3', ['a', 'c'])
// 'https://example.com?b=2'

实际应用示例 ​

获取当前页面参数 ​

ts
import { getUrlParams } from '@bird/utils'

// 在组件中获取路由参数
const params = getUrlParams(window.location.href)
const userId = params.userId
const token = params.token

构建搜索 URL ​

ts
import { qsStringify } from '@bird/utils'

const buildSearchUrl = (query: string, filters: Record<string, any>) => {
  const params = {
    q: query,
    ...filters,
    page: 1
  }
  return `/search?${qsStringify(params)}`
}

const url = buildSearchUrl('keyword', { category: 'tech', sort: 'date' })
// '/search?q=keyword&category=tech&sort=date&page=1'

清理 URL 参数 ​

ts
import { removeUrlParams } from '@bird/utils'

// 关闭弹窗后清理临时参数
const cleanUrl = removeUrlParams(window.location.href, ['modal', 'from'])
window.history.replaceState(null, '', cleanUrl)

分页参数构建 ​

ts
import { qsStringify, getUrlParams } from '@bird/utils'

const usePagination = () => {
  const currentParams = getUrlParams(window.location.href)
  
  const buildPageUrl = (page: number) => {
    const params = {
      ...currentParams,
      page: page.toString()
    }
    return `${window.location.pathname}?${qsStringify(params)}`
  }
  
  return { buildPageUrl }
}

注意事项 ​

  1. 数组参数：当前实现会将数组展开为多个同名的参数
  2. 嵌套对象：不支持嵌套对象的序列化
  3. 特殊字符：会自动编码特殊字符
