element 元素工具

提供 DOM 元素操作相关的实用功能，包括通过 Vue 组件创建元素、判断元素溢出等。

基础用法 ​

ts
import { createElement, createElementToEle, isNodeOverflow } from '@bird/utils'

// 通过 Vue 组件创建元素
const el = createElement(MyComponent, { prop: 'value' })
document.body.appendChild(el)

// 判断元素是否溢出
const overflow = isNodeOverflow(someElement)

创建 Vue 组件元素 ​

ts
import { createElement } from '@bird/utils'
import { ElButton } from 'element-plus'

// 创建 Element Plus 按钮
const button = createElement(ElButton, {
  type: 'primary',
  size: 'small'
}, {
  default: () => '点击'
})

document.body.appendChild(button)

添加组件到指定元素 ​

ts
import { createElementToEle } from '@bird/utils'
import MyModal from './MyModal.vue'

// 添加到 body
const vm = createElementToEle(MyModal, {
  visible: true,
  title: '提示'
})

// 添加到指定元素
const container = document.querySelector('.container')
createElementToEle(MyModal, { visible: true }, container)

判断元素溢出 ​

ts
import { isNodeOverflow } from '@bird/utils'

const textElement = document.querySelector('.text')

if (isNodeOverflow(textElement)) {
  // 添加省略号
  textElement.style.textOverflow = 'ellipsis'
  textElement.style.overflow = 'hidden'
  textElement.style.whiteSpace = 'nowrap'
}

API ​

createElement(component, props, slots) ​

通过 Vue 组件创建 DOM 元素。

参数类型说明
componentComponentVue 组件
propsRecord<string, any>组件属性
slotsRecord<string, any>组件插槽（可选）

返回值： HTMLElement - 创建的 DOM 元素

ts
import { createElement } from '@bird/utils'
import { ElMessage } from 'element-plus'

const message = createElement(ElMessage, {
  type: 'success',
  message: '操作成功'
})

document.body.appendChild(message)

createElementToEle(component, props, appendElement) ​

创建 Vue 组件并添加到指定元素。

参数类型默认值说明
componentComponent-Vue 组件
propsRecord<string, any>{}组件属性
appendElementHTMLElementdocument.body目标元素

返回值： App - Vue 应用实例

ts
import { createElementToEle } from '@bird/utils'
import Modal from './Modal.vue'

// 添加到 body
const vm = createElementToEle(Modal, {
  visible: true,
  onClose: () => vm.unmount()
})

// 添加到指定容器
const container = document.querySelector('.modal-container')
createElementToEle(Modal, { visible: true }, container)

isNodeOverflow(ele) ​

判断节点内容是否溢出。

参数类型说明
eleElement需要检查的 DOM 元素

返回值： boolean - 如果内容溢出返回 true，否则返回 false

ts
const element = document.querySelector('.title')

if (isNodeOverflow(element)) {
  // 内容溢出，可以添加 tooltip
  element.title = element.textContent
}

实际应用示例 ​

动态创建提示消息 ​

ts
import { createElement } from '@bird/utils'
import { ElMessage } from 'element-plus'

const showMessage = (type: string, message: string) => {
  const messageEl = createElement(ElMessage, {
    type,
    message,
    duration: 3000
  })
  
  document.body.appendChild(messageEl)
  
  // 3 秒后移除
  setTimeout(() => {
    messageEl.remove()
  }, 3000)
}

showMessage('success', '操作成功')

动态创建模态框 ​

ts
import { createElementToEle } from '@bird/utils'
import ConfirmDialog from './ConfirmDialog.vue'

const showConfirm = (options: { title: string; onConfirm: () => void }) => {
  const vm = createElementToEle(ConfirmDialog, {
    visible: true,
    title: options.title,
    onConfirm: () => {
      options.onConfirm()
      vm.unmount()
    },
    onCancel: () => {
      vm.unmount()
    }
  })
}

showConfirm({
  title: '确定要删除吗？',
  onConfirm: () => api.delete()
})

文本溢出提示 ​

vue
<template>
  <div ref="textRef" class="text" :title="tooltip">
    {{ content }}
  </div>
</template>

<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { isNodeOverflow } from '@bird/utils'

const props = defineProps<{ content: string }>()
const textRef = ref<HTMLElement>()
const tooltip = ref('')

onMounted(() => {
  if (textRef.value && isNodeOverflow(textRef.value)) {
    tooltip.value = props.content
  }
})
</script>

<style scoped>
.text {
  width: 200px;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
</style>

注意事项 ​

  1. Vue 3 专用：这些方法使用 Vue 3 的 API，不适用于 Vue 2
  2. 手动清理：使用 createElement 创建的元素需要手动移除
  3. 组件卸载：createElementToEle 返回的 vm 实例需要调用 unmount() 来正确清理
  4. 溢出判断限制：isNodeOverflow 只检查宽度方向的溢出
