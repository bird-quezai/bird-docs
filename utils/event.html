event 事件工具

提供简单的事件发射器（EventEmitter）实现，支持事件的订阅、触发和取消。

基础用法 ​

ts
import { EventEmitter } from '@bird/utils'

const emitter = new EventEmitter()

// 订阅事件
emitter.on('click', (data) => {
  console.log('点击事件:', data)
})

// 触发事件
emitter.emit('click', { x: 100, y: 200 })

// 检查是否存在
emitter.has('click') // true

// 取消订阅
emitter.off('click')

事件订阅 ​

ts
import { EventEmitter } from '@bird/utils'

const emitter = new EventEmitter()

// 订阅单个事件
emitter.on('save', () => {
  console.log('保存操作')
})

// 订阅带参数的事件
emitter.on('user:login', (user) => {
  console.log(`${user.name} 登录了`)
})

// 订阅多个参数
emitter.on('data:update', (data, timestamp, source) => {
  console.log(`数据更新：${data}, 时间：${timestamp}, 来源：${source}`)
})

事件触发 ​

ts
import { EventEmitter } from '@bird/utils'

const emitter = new EventEmitter()

// 触发无参数事件
emitter.emit('refresh')

// 触发带参数事件
emitter.emit('user:login', { name: '张三', id: 1 })

// 触发多参数事件
emitter.emit('data:update', { id: 1 }, Date.now(), 'api')

事件取消 ​

ts
import { EventEmitter } from '@bird/utils'

const emitter = new EventEmitter()

// 订阅事件
emitter.on('temp', handler)

// 取消订阅
emitter.off('temp')

API ​

new EventEmitter() ​

创建一个事件发射器实例。

ts
import { EventEmitter } from '@bird/utils'

const emitter = new EventEmitter()

on(eventName, callback) ​

订阅指定事件。

参数类型说明
eventNamestring事件名称
callbackFunction事件回调函数
ts
emitter.on('click', (data) => {
  console.log('点击:', data)
})

// 支持多个监听器
emitter.on('save', () => console.log('保存 1'))
emitter.on('save', () => console.log('保存 2'))
// 触发时会依次调用两个回调

emit(eventName, ...args) ​

触发指定事件。

参数类型说明
eventNamestring事件名称
...argsany[]传递给回调的参数
ts
emitter.emit('click', { x: 100, y: 200 })
emitter.emit('user:update', { id: 1, name: '新名字' })

off(eventName) ​

取消订阅指定事件。

参数类型说明
eventNamestring事件名称
ts
emitter.off('click')  // 取消 click 事件的所有订阅
emitter.off('save')   // 取消 save 事件的所有订阅

has(eventName) ​

检查是否存在指定事件。

参数类型说明
eventNamestring事件名称

返回值： boolean

ts
emitter.on('test', () => {})
emitter.has('test') // true
emitter.has('other') // false

实际应用示例 ​

组件间通信 ​

ts
// eventBus.ts
import { EventEmitter } from '@bird/utils'

export const eventBus = new EventEmitter()

// 在某个组件中订阅
eventBus.on('theme:change', (theme) => {
  console.log('主题变更为:', theme)
})

// 在另一个组件中触发
eventBus.emit('theme:change', 'dark')

全局状态通知 ​

ts
// store.ts
import { EventEmitter } from '@bird/utils'

class Store {
  private emitter = new EventEmitter()
  private state = {}

  subscribe(key: string, callback: (value: any) => void) {
    this.emitter.on(`state:${key}`, callback)
  }

  setState(key: string, value: any) {
    this.state[key] = value
    this.emitter.emit(`state:${key}`, value)
  }

  getState(key: string) {
    return this.state[key]
  }
}

export const store = new Store()

// 使用
store.subscribe('user', (user) => {
  console.log('用户信息更新:', user)
})

store.setState('user', { name: '张三' })

操作日志记录 ​

ts
import { EventEmitter } from '@bird/utils'

const logger = new EventEmitter()

// 记录所有操作
logger.on('action', (action) => {
  console.log(`[${new Date().toISOString()}] ${action.type}`, action.payload)
  // 可以发送到后端
  api.log(action)
})

// 在业务代码中触发
logger.emit('action', { type: 'LOGIN', payload: { userId: 1 } })
logger.emit('action', { type: 'UPDATE', payload: { field: 'name' } })

注意事项 ​

  1. 内存泄漏：组件销毁时记得调用 off() 取消订阅
  2. 错误处理：回调函数中的错误不会影响其他回调的执行
  3. 同步执行：事件触发时回调是同步执行的
  4. 多次订阅：同一个事件可以被多次订阅，触发时按订阅顺序依次执行
