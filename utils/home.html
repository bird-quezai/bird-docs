Bird Utils 工具库概览

Bird Utils 是一个基于 TypeScript 开发的工具函数库，提供了前端开发中常用的高性能工具函数。

安装 ​

bash
npm install @bird/utils
# 或
yarn add @bird/utils
# 或
pnpm add @bird/utils

使用方式 ​

按需引入（推荐） ​

ts
// 引入单个工具函数
import { storage, createNameSpace, downloadFileByALink } from '@bird/utils'

// 使用
storage.setItem('key', 'value')

全局引入 ​

ts
import * as Utils from '@bird/utils'

// 使用
Utils.storage.setItem('key', 'value')

工具模块 ​

createNameSpace - 命名空间生成 ​

用于生成 BEM 格式的 CSS 类名，常用于组件库开发。

ts
import { createNameSpace } from '@bird/utils'

const bem = createNameSpace('button')

// 使用
// bem.b('box') => 'bi-button-box'
// bem.e('icon') => '__icon'
// bem.m('disabled') => '--disabled'
// bem.be('box', 'icon') => 'bi-button-box__icon'
// bem.bem('box', 'icon', 'disabled') => 'bi-button-box__icon--disabled'
// bem.is('checked', true) => 'is-checked'

查看详细文档

storage - 本地存储 ​

封装 localStorage 和 sessionStorage，支持过期时间设置。

ts
import { storage, useStorage } from '@bird/utils'

// 设置带过期时间的数据（1 小时后过期）
storage.setItem('key', 'value', 60 * 60 * 1000)

// 获取数据
const val = storage.getItem('key')

// 删除数据
storage.removeItem('key')

// 自定义 storage（sessionStorage）
const sessionStorage = useStorage(window.sessionStorage, 'prefix_')
sessionStorage.setItem('key', 'value')

查看详细文档

request - HTTP 请求 ​

基于 alova 封装的 HTTP 请求库，支持 Vue 3 组合式 API。

ts
import { createRequest } from '@bird/utils'

const request = createRequest({
  baseURL: 'https://api.example.com',
})

// GET 请求
const data = await request.get('/api/list', { page: 1 })

// POST 请求
await request.post('/api/create', { name: 'test' })

// 上传文件
await request.upload('/api/upload', { file: fileInput.files[0] })

// 下载文件
const blob = await request.download('/api/download', { id: 1 })

文件工具 (file) ​

文件大小格式化、图片判断、文件下载等功能。

ts
import { fileSizeFormat, isImg, downloadFileByALink, iframeDownLoadFile } from '@bird/utils'

// 格式化文件大小
fileSizeFormat(1024) // '1 KB'
fileSizeFormat(1048576) // '1 MB'

// 判断是否是图片
isImg('image/png') // true

// 下载文件
downloadFileByALink('https://example.com/file.pdf', '文件名.pdf')

// iframe 下载
iframeDownLoadFile('https://example.com/download')

字符串工具 (string) ​

随机字符串、UUID 生成、数字转汉字等。

ts
import { getRandomStr, getUuid, numToChinese } from '@bird/utils'

// 生成随机字符串

URL 工具 (url) ​

URL 参数解析、序列化、移除等。

ts
import { getUrlParams, qsStringify, removeUrlParams } from '@bird/utils'

// 获取 URL 参数
getUrlParams('https://example.com?a=1&b=2') // { a: '1', b: '2' }

// 对象转查询字符串
qsStringify({ a: 1, b: 2 }) // 'a=1&b=2'

// 移除 URL 参数
removeUrlParams('https://example.com?a=1&b=2', 'a') // 'https://example.com?b=2'

// 验证身份证
isIDCard('110101199001011234') // true

HTML 工具 (html) ​

HTML 转义、XSS 防护等。

ts
import { sanitizeHtml, escapeHtml, xssEncode, xssDecode } from '@bird/utils'

// 清理 HTML（防 XSS）
sanitizeHtml('<script>alert(1)</script>') // ''

// HTML 转义
escapeHtml('<div>') // '&lt;div&gt;'

// XSS 转义
xssEncode('<script>') // '&lt;script&gt;'

// XSS 反转义
xssDecode('&lt;script&gt;') // '<script>'

事件工具 (event) ​

事件发布订阅模式实现。

ts
import { EventEmitter } from '@bird/utils'

const emitter = new EventEmitter()

// 订阅
emitter.on('event', (data) => {
  console.log(data)
})

// 触发
emitter.emit('event', { msg: 'hello' })

// 检查是否存在
emitter.has('event')

// 取消订阅
emitter.off('event')

类型定义 ​

工具库使用 TypeScript 编写，提供完整的类型定义：

ts
// 存储工具类型
interface StorageUtil {
  setItem(key: string, value: any, exp?: number): void
  getItem(key: string, exp?: number): any
  removeItem(key: string): void
  clear(): void
}

// 请求工具类型
interface RequestUtil {
  get<T>(url: string, params?: Record<string, any>): Promise<T>
  post<T>(url: string, data?: Record<string, any>): Promise<T>
  upload<T>(url: string, data: Record<string, any>): Promise<T>
  download<T>(url: string, params: Record<string, any>): Promise<T>
}
