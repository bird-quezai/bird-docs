html HTML 工具

提供 HTML 处理相关的实用功能，包括 XSS 防护、HTML 转义等安全相关的操作。

基础用法 ​

ts
import { sanitizeHtml, escapeHtml, xssEncode, xssDecode } from '@bird/utils'

// 清理 HTML（防 XSS）
const safeHtml = sanitizeHtml('<script>alert(1)</script><p>Hello</p>')
// '<p>Hello</p>'

// HTML 转义
const escaped = escapeHtml('<div>Hello</div>')
// '&lt;div&gt;Hello&lt;/div&gt;'

// XSS 转义
const encoded = xssEncode('<script>')
// '&lt;script&gt;'

// XSS 反转义
const decoded = xssDecode('&lt;script&gt;')
// '<script>'

XSS 防护 ​

ts
import { sanitizeHtml } from '@bird/utils'

// 清理危险的 HTML 内容
const unsafeHtml = `
  <script>alert('XSS')</script>
  <p onclick="evil()">Hello World</p>
  <iframe src="evil.com"></iframe>
`

const safeHtml = sanitizeHtml(unsafeHtml)
// '<p>Hello World</p>'

HTML 转义 ​

ts
import { escapeHtml } from '@bird/utils'

// 转义 HTML 特殊字符
const str = '<div>Hello & "World"</div>'
const escaped = escapeHtml(str)
// '&lt;div&gt;Hello &amp; &quot;World&quot;&lt;/div&gt;'

XSS 编码/解码 ​

ts
import { xssEncode, xssDecode, xssReplace } from '@bird/utils'

// XSS 编码
const encoded = xssEncode('<p>Hello</p>')
// '&lt;p&gt;Hello&lt;/p&gt;'

// XSS 解码
const decoded = xssDecode('&lt;p&gt;Hello&lt;/p&gt;')
// '<p>Hello</p>'

// 富文本 XSS 处理
const richText = '&lt;p&gt;Hello &amp; World&lt;/p&gt;'
const cleaned = xssReplace(richText)
// '<p>Hello & World</p>'

API ​

sanitizeHtml(html) ​

使用正则表达式清理 HTML 内容，移除潜在的恶意属性和标签，防止 XSS 注入。

参数类型说明
htmlstring需要清理的 HTML 字符串

返回值： string - 清理后的 HTML 字符串

ts
// 移除 script 标签
sanitizeHtml('<script>alert("XSS")</script>') // ''

// 移除 iframe 标签
sanitizeHtml('<iframe src="evil.com"></iframe>') // ''

// 移除事件属性
sanitizeHtml('<div onclick="alert(1)">Hello</div>') // '<div>Hello</div>'

// 移除危险的 href
sanitizeHtml('<a href="javascript:alert(1)">Link</a>') // '<a>Link</a>'

escapeHtml(str) ​

将 HTML 特殊字符转义为 HTML 实体。

参数类型说明
strstring需要转义的字符串

返回值： string - 转义后的字符串

转义规则：

原字符转义后
&&amp;
<&lt;
>&gt;
"&quot;
'&#039;
ts
escapeHtml('<div>Hello & "World"</div>')
// '&lt;div&gt;Hello &amp; &quot;World&quot;&lt;/div&gt;'

xssEncode(str) ​

XSS 转义，将标签转义为字符。

参数类型说明
strstring需要转义的字符串

返回值： string - 转义后的字符串

转义规则：

原字符转义后
<&lt;
>&gt;
&nbsp;
&&amp;
"&quot;
ts
xssEncode('<p>Hello World</p>')
// '&lt;p&gt;Hello World&lt;/p&gt;'

xssDecode(str) ​

XSS 反转义，将字符反转义为标签。

参数类型说明
strstring需要反转义的字符串

返回值： string - 反转义后的字符串

ts
xssDecode('&lt;p&gt;Hello World&lt;/p&gt;')
// '<p>Hello World</p>'

xssReplace(str) ​

富文本 XSS 标签反转义，安全地还原富文本内容。

参数类型说明
strstring需要处理的字符串

返回值： string - 处理后的字符串

ts
// 还原安全的标签
xssReplace('&lt;p&gt;Hello&lt;/p&gt;')
// '<p>Hello</p>'

// 移除危险的属性和标签
xssReplace('&lt;script&gt;alert(1)&lt;/script&gt;')
// ''

实际应用示例 ​

富文本编辑器内容过滤 ​

ts
import { sanitizeHtml } from '@bird/utils'

// 用户提交的富文本内容
const editorContent = `
  <p>正常内容</p>
  <script>alert('XSS')</script>
  <img src="image.jpg" onerror="alert(1)">
`

// 清理后存储
const safeContent = sanitizeHtml(editorContent)
// '<p>正常内容</p><img src="image.jpg">'

// 保存到数据库
await api.saveContent({ content: safeContent })

用户输入显示 ​

vue
<template>
  <div v-html="safeContent"></div>
</template>

<script setup lang="ts">
import { escapeHtml } from '@bird/utils'

const props = defineProps<{
  userContent: string
}>()

// 转义后显示
const safeContent = escapeHtml(props.userContent)
</script>

富文本内容还原 ​

ts
import { xssReplace } from '@bird/utils'

// 从数据库获取的存储内容
const storedContent = '&lt;p&gt;Hello&lt;/p&gt;&lt;img src="a.jpg"&gt;'

// 安全地还原显示
const displayContent = xssReplace(storedContent)
// '<p>Hello</p><img src="a.jpg">'

安全建议 ​

  1. 用户输入必须过滤：所有用户提交的内容在存储前应该使用 sanitizeHtml 过滤
  2. 显示时转义：显示用户内容时使用 escapeHtml 转义
  3. 富文本特殊处理：富文本内容使用 xssReplace 进行安全还原
  4. 不要信任前端：即使前端做了过滤，后端也应该进行二次验证
