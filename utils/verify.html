verify 验证工具

提供常用的数据验证功能，包括手机号、邮箱、身份证、密码强度等验证。

基础用法 ​

ts
import { 
  isMobile, isPhone, isEmail, isIDCard,
  isNumber, isChinese, isValidURL, isPassword 
} from '@bird/utils'

// 判断是否移动端
const mobile = isMobile()

// 验证手机号
const validPhone = isPhone('13800138000') // true

// 验证邮箱
const validEmail = isEmail('test@example.com') // true

// 验证身份证
const validID = isIDCard('110101199001011234') // true

// 验证密码强度
const pwdError = isPassword('Abc123456!', 1) // undefined (验证通过)

设备判断 ​

ts
import { isMobile } from '@bird/utils'

if (isMobile()) {
  // 移动端逻辑
  console.log('当前在移动设备上')
} else {
  // PC 端逻辑
  console.log('当前在 PC 端')
}

格式验证 ​

ts
import { isPhone, isEmail, isIDCard } from '@bird/utils'

// 手机号验证
isPhone('13800138000')  // true
isPhone('12345678901')  // false

// 邮箱验证
isEmail('user@example.com')  // true
isEmail('invalid-email')     // false

// 身份证验证
isIDCard('110101199001011234') // true
isIDCard('12345678901234567X') // true

字符类型验证 ​

ts
import { isNumber, isChinese, isAlphabets } from '@bird/utils'

// 纯数字

// 纯汉字

密码强度验证 ​

ts
import { isPassword } from '@bird/utils'

// 等级 1：必须包含数字和大小写字母，长度至少 8 位，且必须包含特殊字符 (_&#%)
isPassword('MyPass123!', 1)  // undefined (通过)
isPassword('weak', 1)        // '密码必须包含数字和大小写字母，且长度至少 8 位...'

// 等级 2：必须包含数字和大小写字母，长度至少 8 位
isPassword('MyPass123', 2)   // undefined (通过)
isPassword('mypassword', 2)  // '密码必须包含数字和大小写字母，且长度至少 8 位'

// 等级 3：必须包含字母、数字，至少 8 个字符
isPassword('password123', 3) // undefined (通过)
isPassword('password', 3)    // '密码必须包含字母（不区分大小写）、数字，至少 8 个字符'

isPassword(str, level) ​

验证密码强度。

参数类型默认值说明
strstring-密码字符串
level1 | 2 | 31密码强度等级

返回值： string | undefined - 不合规时返回提示信息，合规时返回 undefined

强度等级说明：

等级要求
1必须包含数字和大小写字母，长度至少 8 位，且必须包含特殊字符 (_&#%)
2必须包含数字和大小写字母，长度至少 8 位
3必须包含字母、数字，至少 8 个字符
ts
isPassword('MyPass123!', 1)  // undefined
isPassword('weak', 1)        // 错误提示信息

实际应用示例 ​

表单验证 ​

vue
<template>
  <el-form :model="form" :rules="rules">
    <el-form-item label="手机号" prop="phone">
      <el-input v-model="form.phone" />
    </el-form-item>
    <el-form-item label="邮箱" prop="email">
      <el-input v-model="form.email" />
    </el-form-item>
  </el-form>
</template>

<script setup lang="ts">
import { isPhone, isEmail } from '@bird/utils'

const form = ref({ phone: '', email: '' })

const rules = {
  phone: [
    { 
      validator: (rule, value) => {
        if (!value) return Promise.reject('请输入手机号')
        if (!isPhone(value)) return Promise.reject('手机号格式不正确')
        return Promise.resolve()
      }
    }
  ],
  email: [
    {
      validator: (rule, value) => {
        if (!value) return Promise.reject('请输入邮箱')
        if (!isEmail(value)) return Promise.reject('邮箱格式不正确')
        return Promise.resolve()
      }
    }
  ]
}
</script>

密码强度检查 ​

ts
import { isPassword } from '@bird/utils'

const validatePassword = (password: string) => {
  const error = isPassword(password, 2)
  if (error) {
    return { valid: false, message: error }
  }
  return { valid: true, message: '密码符合要求' }
}

validatePassword('weak')      // { valid: false, message: '密码必须包含...' }
validatePassword('MyPass123') // { valid: true, message: '密码符合要求' }
