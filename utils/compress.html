compress 压缩工具

提供文件压缩相关的实用功能，主要包括文件转 Base64、图片压缩等。

基础用法 ​

ts
import { fileToBase64, imgCompress } from '@bird/utils'

// 文件转 Base64
const base64 = await fileToBase64(file)

// 压缩图片
const compressedFile = await imgCompress(file, {
  quality: 0.8,
  maxWidth: 800,
  maxHeight: 600
})

文件转 Base64 ​

ts
import { fileToBase64 } from '@bird/utils'

// 选择文件后转换
const fileInput = document.querySelector('input[type="file"]')
const file = fileInput.files[0]

const base64 = await fileToBase64(file)
console.log(base64) // 'data:image/png;base64,iVBORw0KG...'

// 用于图片预览
const img = document.createElement('img')
img.src = base64
document.body.appendChild(img)

图片压缩 ​

ts
import { imgCompress } from '@bird/utils'

// 获取选中的文件
const file = fileInput.files[0]

// 压缩图片
const compressedFile = await imgCompress(file, {
  quality: 0.7,    // 压缩质量 0.7
  maxWidth: 800,   // 最大宽度 800px
  maxHeight: 600   // 最大高度 600px
})

console.log(`原文件大小：${file.size} bytes`)
console.log(`压缩后大小：${compressedFile.size} bytes`)

压缩后上传 ​

ts
import { imgCompress } from '@bird/utils'

const uploadCompressedImage = async (file: File) => {
  // 先压缩
  const compressedFile = await imgCompress(file, {
    quality: 0.8,
    maxWidth: 1024
  })
  
  // 上传压缩后的文件
  const formData = new FormData()
  formData.append('image', compressedFile)
  
  await fetch('/api/upload', {
    method: 'POST',
    body: formData
  })
}

API ​

fileToBase64(file) ​

将文件转换为 Base64 字符串。

参数类型说明
fileFile需要转换的文件

返回值： Promise<string> - Base64 字符串（包含 data URI 前缀）

ts
const file = new File(['hello'], 'test.txt', { type: 'text/plain' })
const base64 = await fileToBase64(file)
// 'data:text/plain;base64,aGVsbG8='

imgCompress(file, options) ​

对图片进行压缩处理。

参数类型说明
fileFile需要压缩的文件
options.qualitynumber压缩质量，默认为 0.8（0-1 之间）
options.maxWidthnumber最大宽度，超过则等比缩放
options.maxHeightnumber最大高度，超过则等比缩放

返回值： Promise<File> - 压缩后的文件

ts
// 仅压缩质量
await imgCompress(file, { quality: 0.6 })

// 限制最大宽度
await imgCompress(file, { maxWidth: 800 })

// 限制最大高度
await imgCompress(file, { maxHeight: 600 })

// 组合使用
await imgCompress(file, { 
  quality: 0.7, 
  maxWidth: 800, 
  maxHeight: 600 
})

实际应用示例 ​

头像上传 ​

vue
<template>
  <input type="file" accept="image/*" @change="handleFileSelect" />
  <img v-if="preview" :src="preview" alt="预览" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { fileToBase64, imgCompress } from '@bird/utils'

const preview = ref('')
const compressedFile = ref<File | null>(null)

const handleFileSelect = async (e: Event) => {
  const file = (e.target as HTMLInputElement).files?.[0]
  if (!file) return
  
  // 压缩图片
  compressedFile.value = await imgCompress(file, {
    quality: 0.8,
    maxWidth: 200,
    maxHeight: 200
  })
  
  // 生成预览
  preview.value = await fileToBase64(compressedFile.value)
}

const uploadAvatar = async () => {
  if (!compressedFile.value) return
  
  const formData = new FormData()
  formData.append('avatar', compressedFile.value)
  
  await fetch('/api/upload/avatar', {
    method: 'POST',
    body: formData
  })
}
</script>

批量图片压缩上传 ​

ts
import { imgCompress } from '@bird/utils'

const uploadImages = async (files: File[]) => {
  const compressedFiles = await Promise.all(
    files.map(file => imgCompress(file, {
      quality: 0.7,
      maxWidth: 1920
    }))
  )
  
  const formData = new FormData()
  compressedFiles.forEach((file, index) => {
    formData.append(`image${index}`, file)
  })
  
  await fetch('/api/upload/images', {
    method: 'POST',
    body: formData
  })
}

注意事项 ​

  1. 仅支持图片：imgCompress 只对图片类型文件有效，非图片文件会原样返回
  2. 自动跳过小文件：小于 300KB 的文件不会压缩，直接返回原文件
  3. Canvas 压缩：使用 Canvas API 进行压缩，可能会有轻微的质量损失
  4. 异步操作：两个方法都是异步的，需要使用 await 或 Promise

压缩建议 ​

用途建议质量建议最大宽度
头像/缩略图0.7-0.8200-400px
文章配图0.7-0.8800-1200px
高清展示0.8-0.91920px
原始备份0.9-1.0不限制
