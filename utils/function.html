function 函数工具

提供函数操作相关的实用功能，主要用于条件等待和异步处理。

基础用法 ​

ts
import { dataExistCallFun } from '@bird/utils'

// 等待某个条件满足
await dataExistCallFun(() => {
  return document.querySelector('.target') !== null
})

console.log('条件满足，继续执行')

等待 DOM 元素 ​

ts
import { dataExistCallFun } from '@bird/utils'

// 等待元素出现在 DOM 中
await dataExistCallFun(() => !!document.getElementById('my-element'))

// 元素已存在，可以安全操作
const element = document.getElementById('my-element')
element.textContent = 'Hello'

等待数据加载 ​

ts
import { dataExistCallFun } from '@bird/utils'

// 等待数据加载完成
await dataExistCallFun(
  () => window.myData && window.myData.loaded,
  { time: 200, maxNum: 50 }
)

// 数据已加载，可以使用
console.log(window.myData)

等待 Vue 实例初始化 ​

ts
import { dataExistCallFun } from '@bird/utils'

// 等待 Vue 实例初始化完成
await dataExistCallFun(() => !!window.vueApp)

// 使用 Vue 实例
window.vueApp.$mount('#app')

API ​

dataExistCallFun(passFun, options) ​

条件函数通过时执行回调。当条件函数返回 true 时，Promise 解析为成功；否则会定期重试直到达到最大次数。

参数类型默认值说明
passFunFunction-条件函数，返回布尔值
options.timenumber100重试间隔时间（毫秒）
options.timeKeystring自动生成计时器标识符
options.maxNumnumber100最大重试次数

返回值： Promise<boolean> - 条件满足时解析为 true，超出最大重试次数时拒绝

ts
// 基本用法
await dataExistCallFun(() => !!document.querySelector('.target'))

// 自定义配置
await dataExistCallFun(
  () => !!document.querySelector('.target'),
  { time: 500, maxNum: 20 }
)

实际应用示例 ​

等待第三方脚本加载 ​

ts
import { dataExistCallFun } from '@bird/utils'

// 加载第三方脚本
const script = document.createElement('script')
script.src = 'https://maps.googleapis.com/maps/api/js?key=YOUR_KEY'
document.head.appendChild(script)

// 等待 Google Maps API 加载完成
await dataExistCallFun(() => !!window.google?.maps)

// 现在可以安全使用 Google Maps API
const map = new google.maps.Map(document.getElementById('map'), {
  center: { lat: 40.7128, lng: -74.0060 },
  zoom: 8
})

等待 WebSocket 连接 ​

ts
import { dataExistCallFun } from '@bird/utils'

const ws = new WebSocket('ws://example.com')

// 等待 WebSocket 连接成功
await dataExistCallFun(() => ws.readyState === WebSocket.OPEN, {
  time: 100,
  maxNum: 100
})

// 发送消息
ws.send(JSON.stringify({ type: 'init', data: {} }))

等待 Store 初始化 ​

ts
import { dataExistCallFun } from '@bird/utils'

// 在组件中等待 Store 初始化完成
await dataExistCallFun(() => store && store.state)

// 访问 Store 数据
const userData = store.state.user

等待异步数据加载 ​

ts
import { dataExistCallFun } from '@bird/utils'

// 等待多个异步数据加载完成
const loadData = async () => {
  api.getUserData()
  api.getConfig()
  api.getPermissions()
  
  // 等待所有数据加载完成
  await dataExistCallFun(() => {
    return window.appData?.user && 
           window.appData?.config && 
           window.appData?.permissions
  }, { time: 100, maxNum: 50 })
  
  // 初始化应用
  initApp()
}

注意事项 ​

  1. 超时处理：达到最大重试次数后 Promise 会被拒绝，建议添加错误处理
  2. 时间间隔：时间间隔不宜过短，避免频繁检测影响性能
  3. 内存泄漏：每个检测会创建一个计时器，组件销毁时注意清理
  4. 条件函数：条件函数应该是幂等的，不会产生副作用

错误处理 ​

ts
import { dataExistCallFun } from '@bird/utils'

try {
  await dataExistCallFun(
    () => !!document.querySelector('.target'),
    { time: 100, maxNum: 50 }
  )
} catch (error) {
  console.error('等待超时，条件未满足')
  // 处理超时情况
}
