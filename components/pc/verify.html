BiVerify 滑块验证组件

介绍 ​

BiVerify（VoVerify）是一个滑块拼图验证组件，提供安全且用户友好的验证方式。用户需要拖动滑块到正确位置完成拼图来验证身份，适用于防止机器自动化操作的场景。

基础用法 ​

最简单的用法是通过 on-get 和 on-check 回调函数来配置验证逻辑。

vue
<template>
  <bi-verify-slide 
    :on-get="onGetCaptcha" 
    :on-check="onCheckCaptcha" 
    @success="onSuccess"
    @close="onClose" 
  />
</template>

<script setup lang="ts">
// 获取验证码回调
const onGetCaptcha = async (params: { captchaType: string }) => {
  // 调用后端接口获取验证码
  const res = await fetch('/api/captcha/get', {
    method: 'POST',
    body: JSON.stringify(params)
  })
  return await res.json()
  // 返回格式：
  // {
  //   repCode: '0000',
  //   repData: {
  //     originalImageBase64: 'base64 背景图',
  //     jigsawImageBase64: 'base64 滑块图',
  //     token: '验证令牌',
  //     secretKey: '加密密钥'
  //   },
  //   repMsg: 'success'
  // }
}

// 核对验证码回调
const onCheckCaptcha = async (data: { 
  captchaType: string
  pointJson: string
  token: string
}) => {
  // 调用后端接口验证
  const res = await fetch('/api/captcha/check', {
    method: 'POST',
    body: JSON.stringify(data)
  })
  return await res.json()
  // 返回格式：
  // {
  //   repCode: '0000', // '0000' 表示验证成功
  //   repMsg: '验证成功'
  // }
}

// 验证成功回调
const onSuccess = (data: { captchaVerification: string }) => {
  console.log('验证成功', data.captchaVerification)
  // captchaVerification 是加密后的验证信息，可用于后续业务接口
}

// 关闭回调
const onClose = () => {
  console.log('验证关闭')
}
</script>

弹窗模式 ​

通过设置 mode 属性为 dialog，以弹窗形式显示验证组件。

vue
<template>
  <div>
    <el-button @click="showVerify = true">打开验证</el-button>
    
    <bi-verify-slide 
      v-if="showVerify"
      mode="dialog"
      :on-get="onGetCaptcha" 
      :on-check="onCheckCaptcha" 
      @success="onSuccess"
      @close="onClose" 
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const showVerify = ref(false)

const onGetCaptcha = async (params: { captchaType: string }) => {
  // 实现获取验证码逻辑
}

const onCheckCaptcha = async (data: any) => {
  // 实现验证逻辑
}

const onSuccess = (data: { captchaVerification: string }) => {
  showVerify.value = false
  console.log('验证成功', data.captchaVerification)
}

const onClose = () => {
  showVerify.value = false
}
</script>

完整示例 ​

vue
<template>
  <div class="verify-demo">
    <el-button type="primary" @click="showDialog = true">
      打开滑块验证
    </el-button>

    <bi-verify-slide 
      v-if="showDialog"
      mode="dialog"
      :on-get="onGetCaptcha" 
      :on-check="onCheckCaptcha" 
      @success="handleSuccess"
      @close="handleClose" 
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { ElMessage } from 'element-plus'

const showDialog = ref(false)

// 模拟 API 调用
const onGetCaptcha = async (params: { captchaType: string }) => {
  try {
    const response = await fetch('/api/captcha/get', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(params)
    })
    
    if (!response.ok) throw new Error('网络响应失败')
    
    const result = await response.json()
    
    if (result.repCode !== '0000') {
      ElMessage.error(result.repMsg || '获取验证码失败')
      throw new Error(result.repMsg)
    }
    
    return result
  } catch (error) {
    console.error('获取验证码失败:', error)
    throw error
  }
}

const onCheckCaptcha = async (data: {
  captchaType: string
  pointJson: string
  token: string
}) => {
  try {
    const response = await fetch('/api/captcha/check', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data)
    })
    
    const result = await response.json()
    
    if (result.repCode !== '0000') {
      ElMessage.error(result.repMsg || '验证失败')
    }
    
    return result
  } catch (error) {
    console.error('验证失败:', error)
    throw error
  }
}

const handleSuccess = (data: { captchaVerification: string }) => {
  showDialog.value = false
  ElMessage.success('验证成功')
  console.log('验证凭证:', data.captchaVerification)
  // 这里可以将 captchaVerification 传递到后端进行后续业务操作
}

const handleClose = () => {
  showDialog.value = false
}
</script>

API ​

属性 ​

属性类型默认值说明
mode'dialog' | 'base''base'组件显示模式
on-getFunction-获取验证码的回调函数（必填）
on-checkFunction-核对验证码的回调函数（必填）

事件 ​

事件名说明回调参数
success验证成功时触发{ captchaVerification: string }
close组件关闭时触发-

onGet 回调参数 ​

参数说明类型
captchaType验证类型'blockPuzzle'

onGet 回调返回值 ​

返回一个 Promise，resolve 后返回以下对象：

属性说明类型
repCode响应码，'0000' 表示成功string
repData响应数据object
repMsg响应消息string

repData 结构 ​

属性说明类型
originalImageBase64背景图片的 base64 编码string
jigsawImageBase64滑块图片的 base64 编码string
token验证令牌string
secretKey加密密钥string

onCheck 回调参数 ​

参数说明类型
captchaType验证类型'blockPuzzle'
pointJson加密后的坐标信息string
token验证令牌string

onCheck 回调返回值 ​

返回一个 Promise，resolve 后返回以下对象：

属性说明类型
repCode响应码，'0000' 表示验证成功string
repMsg响应消息string

后端接口说明 ​

1. 获取验证码接口 ​

请求示例：

json
POST /api/captcha/get
{
  "captchaType": "blockPuzzle"
}

响应示例：

json
{
  "repCode": "0000",
  "repData": {
    "originalImageBase64": "data:image/png;base64,iVBORw0KG...",
    "jigsawImageBase64": "data:image/png;base64,iVBORw0KG...",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "secretKey": "XwKsGlMcdPMEhR1B"
  },
  "repMsg": "success"
}

2. 验证验证码接口 ​

请求示例：

json
POST /api/captcha/check
{
  "captchaType": "blockPuzzle",
  "pointJson": "encrypted_point_json",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}

响应示例：

json
{
  "repCode": "0000",
  "repMsg": "验证成功"
}

注意事项 ​

  1. onGet 和 onCheck 是必需的属性，必须提供有效的回调函数
  2. 在 dialog 模式下，组件会以固定定位覆盖整个页面
  3. 组件内部使用 AES 加密算法对坐标信息进行加密，确保数据传输安全
  4. 验证成功后返回的 captchaVerification 可用于后续业务接口的验证
  5. 组件会自动处理验证成功和失败的状态显示
