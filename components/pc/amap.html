BiAmap 高德地图组件

介绍 ​

BiAmap 是基于高德地图 JS API 2.0 封装的地图组件，提供了一系列地图相关的子组件，包括标记点、折线、多边形、标记聚合、大数据量标记、标签标记等功能。适用于需要在应用中集成地图展示和交互的场景。

基础用法 ​

最简单的用法是使用 BiAmap 主组件来显示地图。

vue
<template>
  <bi-amap style="width: 100%; height: 500px" />
</template>

<script setup lang="ts">
// 组件会自动初始化地图
</script>

自定义地图配置 ​

通过 map-options 属性配置地图初始状态。

vue
<template>
  <bi-amap 
    style="width: 100%; height: 500px"
    :map-options="{
      center: [116.397428, 39.90923],
      zoom: 12,
      mapStyle: 'amap://styles/darkblue'
    }"
  />
</template>

添加标记点 ​

使用 BiAmapMarker 子组件添加标记点。

vue
<template>
  <bi-amap style="width: 100%; height: 500px">
    <bi-amap-marker 
      :markers="[
        { lng: 116.397428, lat: 39.90923, title: '北京' },
        { lng: 121.473701, lat: 31.230416, title: '上海' }
      ]"
    />
  </bi-amap>
</template>

<script setup lang="ts">
// markers 数组支持多个标记点
</script>

大数据量标记 ​

使用 BiAmapMassMarks 子组件展示大量数据点。

vue
<template>
  <bi-amap style="width: 100%; height: 500px">
    <bi-amap-mass-marks 
      :mass-marks="massData"
      :options="massOptions"
    />
  </bi-amap>
</template>

<script setup lang="ts">
import { ref } from 'vue'

// 生成 1000 个随机数据点
const massData = ref(
  Array.from({ length: 1000 }, () => ({
    lng: 116 + Math.random() * 5,
    lat: 39 + Math.random() * 5,
    weight: Math.random() * 10
  }))
)

const massOptions = {
  size: 10,
  unit: 'px'
}
</script>

地图事件监听 ​

vue
<template>
  <bi-amap 
    style="width: 100%; height: 500px"
    @init="handleMapInit"
  />
</template>

<script setup lang="ts">
const handleMapInit = (mapInstance: AMap.Map) => {
  console.log('地图初始化完成', mapInstance)
  
  // 监听地图点击事件
  mapInstance.on('click', (e: AMap MapsEvent) => {
    console.log('地图点击位置:', e.lnglat)
  })
  
  // 监听地图移动事件
  mapInstance.on('moveend', () => {
    console.log('地图移动结束')
  })
  
  // 监听缩放事件
  mapInstance.on('zoomchange', () => {
    console.log('缩放级别变化:', mapInstance.getZoom())
  })
}
</script>

获取地图实例 ​

vue
<template>
  <bi-amap 
    ref="mapRef"
    style="width: 100%; height: 500px"
  />
  <el-button @click="getMapInfo">获取地图信息</el-button>
</template>

<script setup lang="ts">
import { ref, inject } from 'vue'
import type { MapObj } from '@/components/amap'

const mapRef = ref()
const mapObj = inject<MapObj>('mapObj')

const getMapInfo = () => {
  if (mapObj?.mapInstance) {
    console.log('中心点:', mapObj.mapInstance.getCenter())
    console.log('缩放级别:', mapObj.mapInstance.getZoom())
  }
}
</script>

完整示例：店铺位置展示 ​

vue
<template>
  <div class="map-container">
    <bi-amap 
      ref="mapRef"
      style="width: 100%; height: 600px"
      :map-options="{
        center: [116.397428, 39.90923],
        zoom: 12
      }"
      @init="handleMapInit"
    >
      <!-- 店铺标记点 -->
      <bi-amap-marker 
        :markers="storeMarkers"
        @click="handleMarkerClick"
      />
      
      <!-- 配送范围多边形 -->
      <bi-amap-polygon 
        :polygons="deliveryPolygons"
      />
    </bi-amap>
    
    <div class="map-controls">
      <el-button @click="zoomIn">放大</el-button>
      <el-button @click="zoomOut">缩小</el-button>
      <el-button @click="resetView">复位</el-button>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, inject, type Ref } from 'vue'
import type { MapObj } from '@/components/amap'

interface Marker {
  lng: number
  lat: number
  title: string
  content?: string
}

const mapRef = ref()
const mapObj = inject<MapObj>('mapObj')

// 店铺标记点
const storeMarkers = ref<Marker[]>([
  {
    lng: 116.397428,
    lat: 39.90923,
    title: '北京店',
    content: '<div style="padding:5px;">北京市朝阳区</div>'
  },
  {
    lng: 121.473701,
    lat: 31.230416,
    title: '上海店',
    content: '<div style="padding:5px;">上海市浦东新区</div>'
  }
])

// 配送范围
const deliveryPolygons = ref([
  {
    path: [
      [116.387428, 39.89923],
      [116.407428, 39.89923],
      [116.407428, 39.91923],
      [116.387428, 39.91923]
    ],
    strokeColor: '#FF0000',
    fillColor: '#FF0000',
    fillOpacity: 0.2
  }
])

const handleMapInit = (map: AMap.Map) => {
  console.log('地图已初始化')
}

const handleMarkerClick = (marker: Marker) => {
  console.log('点击了标记点:', marker.title)
}

const zoomIn = () => {
  mapObj?.mapInstance?.setZoom(mapObj.mapInstance.getZoom() + 1)
}

const zoomOut = () => {
  mapObj?.mapInstance?.setZoom(mapObj.mapInstance.getZoom() - 1)
}

const resetView = () => {
  mapObj?.mapInstance?.setCenter([116.397428, 39.90923])
  mapObj?.mapInstance?.setZoom(12)
}
</script>

  position: absolute;
  top: 10px;
  right: 10px;
  display: flex;
  flex-direction: column;
  gap: 10px;
}
</style>

API ​

BiAmap 主组件 ​

属性

属性类型默认值说明
map-keystring-高德地图 Web 端开发者 Key
security-js-codestring-安全密钥（用于高德地图 2.0）
map-optionsAMap.MapOptions-地图配置选项
debugbooleanfalse是否开启调试日志（生产环境应保持关闭）

事件

事件名说明回调参数
init地图初始化完成时触发mapInstance: AMap.Map
click地图点击事件event: unknown
error地图初始化失败时触发（密钥缺失、网络错误等）error: unknown

暴露的方法

方法名说明
getMapInstance获取地图实例

类型定义 ​

ts
interface Marker {
  lng: number;
  lat: number;
  title?: string;
  content?: string;
  icon?: string;
  offset?: [number, number];
  draggable?: boolean;
  visible?: boolean;
}

interface Polyline {
  path: [number, number][];
  strokeColor?: string;
  strokeWeight?: number;
  strokeStyle?: 'solid' | 'dashed' | 'dotted';
  strokeOpacity?: number;
}

interface Polygon {
  path: [number, number][];
  strokeColor?: string;
  strokeWeight?: number;
  fillColor?: string;
  fillOpacity?: number;
}

interface ClusterMarker {
  lng: number;
  lat: number;
}

interface MassMarkDataItem {
  lng: number;
  lat: number;
  weight?: number;
}

interface LabelMarker {
  lng: number;
  lat: number;
  name?: string;
  content?: string;
}

interface MapObj {
  AMap: typeof window.AMap;
  mapInstance: AMap.Map | null;
}

注意事项 ​

  1. 使用地图前需要在高德开放平台申请 Web 端 Developer Key
  2. 高德地图 2.0 需要配置安全密钥（securityJsCode）
  3. 组件会自动加载高德地图 JS API
  4. 所有子组件都通过 provide/inject 共享地图实例
  5. 标记点聚合适用于展示大量标记点的场景
  6. 大数据量标记适用于展示成千上万个数据点的场景
