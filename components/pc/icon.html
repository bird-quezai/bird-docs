BiIcon 图标组件

介绍 ​

BiIcon 是一个基础的图标组件，用于在应用中显示图标。它基于 Element Plus 图标体系，支持自定义颜色和大小。

基础用法 ​

通过默认插槽传入图标组件即可显示。

vue
<template>
  <div class="icon-demo">
    <bi-icon>
      <el-icon><Search /></el-icon>
    </bi-icon>
    <bi-icon :size="30" color="#409EFF">
      <el-icon><Star /></el-icon>
    </bi-icon>
    <bi-icon :size="40" color="#67C23A">
      <el-icon><Check /></el-icon>
    </bi-icon>
  </div>
</template>

<script setup lang="ts">
import { Search, Star, Check } from '@element-plus/icons-vue'
</script>

<style scoped>
.icon-demo {
  display: flex;
  gap: 20px;
  align-items: center;
}
</style>

自定义大小 ​

通过 size 属性设置图标大小，支持数字（单位为 px）和字符串（如 '2em'）。

vue
<template>
  <div class="icon-demo">
    <bi-icon :size="16"><el-icon><Search /></el-icon></bi-icon>
    <bi-icon :size="24"><el-icon><Search /></el-icon></bi-icon>
    <bi-icon :size="32"><el-icon><Search /></el-icon></bi-icon>
    <bi-icon size="2em"><el-icon><Search /></el-icon></bi-icon>
  </div>
</template>

<script setup lang="ts">
import { Search } from '@element-plus/icons-vue'
</script>

<style scoped>
.icon-demo {
  display: flex;
  gap: 20px;
  align-items: center;
}
</style>

自定义颜色 ​

通过 color 属性设置图标颜色。

vue
<template>
  <div class="icon-demo">
    <bi-icon color="#F56C6C"><el-icon><Close /></el-icon></bi-icon>
    <bi-icon color="#409EFF"><el-icon><Info /></el-icon></bi-icon>
    <bi-icon color="#67C23A"><el-icon><Check /></el-icon></bi-icon>
    <bi-icon color="#E6A23C"><el-icon><Warning /></el-icon></bi-icon>
  </div>
</template>

<script setup lang="ts">
import { Close, Info, Check, Warning } from '@element-plus/icons-vue'
</script>

<style scoped>
.icon-demo {
  display: flex;
  gap: 20px;
  align-items: center;
}
</style>

API ​

属性 ​

属性类型默认值说明
sizenumber | string-图标大小，数字单位为 px
colorstring-图标颜色

插槽 ​

插槽名说明
default图标内容，通常传入 Element Plus 图标组件

示例代码 ​

vue
<template>
  <bi-icon :size="24" color="#409EFF">
    <el-icon><Search /></el-icon>
  </bi-icon>
</template>

<script setup lang="ts">
import { Search } from '@element-plus/icons-vue'
</script>
