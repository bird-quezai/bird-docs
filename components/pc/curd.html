BiCurd 通用 CRUD 组件

介绍 ​

BiCurd 是一个用于快速构建增删改查（Create, Read, Update, Delete）界面的业务组件。它封装了列表展示、搜索、分页、新增、编辑、删除、导入、导出等常用功能，通过简单的配置即可生成完整的 CRUD 界面，大大减少了重复开发工作。

基础用法 ​

最简用法需要提供三个属性：name（模块名称）、columns（表单/表格字段配置）和 api-list（API 接口集合）。

其中 api-list 接收一个对象，包含 listApi 等方法，组件会根据方法是否存在自动显示对应的新增/编辑/删除/导入/导出按钮。

vue
<template>
  <bi-curd name="用户管理" :columns="columns" :api-list="userApi" />
</template>

<script setup lang="ts">
const columns = [
  { prop: 'name', label: '姓名', type: 'input' },
  { prop: 'age', label: '年龄', type: 'number' },
  { prop: 'email', label: '邮箱', type: 'email' },
]

const userApi = {
  listApi: async (query) => {
    // query = { pageNum, pageSize, ...搜索条件 }
    const res = await fetch('/api/user/list', { method: 'POST', body: JSON.stringify(query) })
    const data = await res.json()
    return { rows: data.list, total: data.total }
  },
}
</script>

完整 API 配置 ​

配置所有 API 方法以启用完整的增删改查功能。

vue
<template>
  <bi-curd name="用户管理" :columns="columns" :api-list="userApi" />
</template>

<script setup lang="ts">
const columns = [
  { prop: 'name', label: '姓名', type: 'input' },
  { prop: 'age', label: '年龄', type: 'number' },
  { prop: 'email', label: '邮箱', type: 'email' },
]

const userApi = {
  listApi: async (query) => {
    const res = await fetch('/api/user/list', { method: 'POST', body: JSON.stringify(query) })
    const data = await res.json()
    return { rows: data.list, total: data.total }
  },
  detailApi: async (id) => {
    const res = await fetch(`/api/user/${id}`)
    return res.json()
  },
  addApi: async (data) => {
    await fetch('/api/user/add', { method: 'POST', body: JSON.stringify(data) })
  },
  editApi: async (data) => {
    await fetch('/api/user/edit', { method: 'POST', body: JSON.stringify(data) })
  },
  delApi: async (ids) => {
    await fetch('/api/user/delete', { method: 'POST', body: JSON.stringify({ ids }) })
  },
  templateApi: async () => {
    // 返回模板文件
    return fetch('/api/user/template').then((r) => r.blob())
  },
  importApi: async (...args) => {
    await fetch('/api/user/import', { method: 'POST' /* , body */ })
  },
  exportApi: async (row) => {
    return fetch('/api/user/export', { method: 'POST', body: JSON.stringify(row) }).then((r) => r.blob())
  },
}
</script>

搜索表单 ​

通过 columns 中的字段配置 + search-filters 控制哪些字段出现在搜索区域，配合 search-form-line-amount 控制每行显示数量。

vue
<template>
  <bi-curd
    name="用户管理"
    :columns="columns"
    :api-list="userApi"
    :search-filters="['name', 'email', 'status']"
    :search-form-line-amount="3"
    :search-form-data="{ status: 1 }"
  />
</template>

<script setup lang="ts">
const columns = [
  { prop: 'name', label: '姓名', type: 'input' },
  { prop: 'age', label: '年龄', type: 'number' },
  { prop: 'email', label: '邮箱', type: 'input' },
  { prop: 'phone', label: '手机号', type: 'input' },
  {
    prop: 'status',
    label: '状态',
    type: 'select',
    options: [
      { label: '启用', value: 1 },
      { label: '禁用', value: 0 },
    ],
  },
]

const userApi = {
  listApi: async (query) => ({ rows: [], total: 0 }),
}
</script>

表格列过滤 ​

使用 table-filters 指定表格实际显示的列（可以是字符串数组或函数）。

vue
<template>
  <bi-curd
    name="用户管理"
    :columns="columns"
    :api-list="userApi"
    :table-filters="(cols) => cols.filter((c) => c.prop !== 'password')"
  />
</template>

<script setup lang="ts">
const columns = [
  { prop: 'username', label: '用户名' },
  { prop: 'password', label: '密码' },
  { prop: 'email', label: '邮箱' },
  { prop: 'createTime', label: '创建时间' },
]

const userApi = {
  listApi: async (query) => ({ rows: [], total: 0 }),
}
</script>

自定义操作列内容 ​

通过 #extra 插槽在操作列追加自定义按钮。

vue
<template>
  <bi-curd name="用户管理" :columns="columns" :api-list="userApi">
    <template #extra="{ row }">
      <el-button type="primary" link @click="handleResetPassword(row)">
        重置密码
      </el-button>
      <el-button type="warning" link @click="handleExport(row)">
        导出
      </el-button>
    </template>
  </bi-curd>
</template>

<script setup lang="ts">
const columns = [
  { prop: 'name', label: '姓名' },
  { prop: 'age', label: '年龄' },
]

const userApi = {
  listApi: async (query) => ({ rows: [], total: 0 }),
  editApi: async () => {},
  delApi: async () => {},
}

const handleResetPassword = (row) => console.log('重置密码:', row)
const handleExport = (row) => console.log('导出:', row)
</script>

禁用新增按钮 ​

当没有新增权限时，设置 add-disabled 隐藏新增按钮。

vue
<template>
  <bi-curd
    name="用户管理"
    :columns="columns"
    :api-list="userApi"
    :add-disabled="!hasPermission('user:add')"
  />
</template>

详情模式 ​

在新增/编辑弹窗中，type: 'date' 等字段会在详情模式下自动变成只读展示。也可以通过 hidden 在编辑时隐藏敏感字段。

vue
<script setup lang="ts">
const columns = [
  { prop: 'username', label: '用户名', type: 'input' },
  {
    prop: 'password',
    label: '密码',
    type: 'password',
    hidden: (formData) => !!formData.id, // 编辑/详情时隐藏密码字段
  },
  { prop: 'email', label: '邮箱', type: 'email' },
]
</script>

API 接口定义 ​

Api 类型 ​

方法类型说明
listApi(query) => Promise<PageResult<T>>获取列表数据（必填）
detailApi(id) => Promise<T>获取详情数据
addApi(data) => Promise<unknown>新增数据
editApi(data) => Promise<unknown>更新数据
delApi(ids) => Promise<unknown>删除数据（支持单个或数组）
templateApi(...args) => Promise<string | Blob | ArrayBuffer>下载导入模板
importApi(...args) => Promise<unknown>导入数据
exportApi(data) => Promise<string | Blob | ArrayBuffer>导出数据

PageResult 类型 ​

属性类型说明
rowsT[]列表数据数组
totalnumber数据总数

listApi 查询参数 ​

参数类型说明
pageNumnumber当前页码
pageSizenumber每页条数
...unknown其余为搜索表单的字段值

类型定义 ​

ts
export interface PageResult<T> {
  rows: T[]
  total: number
}

export interface Api<T = Record<string, unknown>> {
  listApi: (query: { pageNum?: number; pageSize?: number; [key: string]: unknown }) => Promise<PageResult<T>>
  detailApi: (id: number | string) => Promise<T>
  addApi: (data: T) => Promise<unknown>
  editApi: (data: T) => Promise<unknown>
  delApi: (ids: number | string | (number | string)[]) => Promise<unknown>
  templateApi?: (...args: Record<string, unknown>[]) => Promise<string | Blob | ArrayBuffer>
  importApi?: (...args: Record<string, unknown>[]) => Promise<unknown>
  exportApi?: (data: T) => Promise<string | Blob | ArrayBuffer>
}

type ColumnFilters = (
  | string
  | number
  | FormField
  | TableColumn
)[] | ((columns: FormField[]) => FormField[])

完整示例 ​

vue
<template>
  <bi-curd
    name="用户管理"
    :columns="columns"
    :api-list="userApi"
    :search-filters="['username', 'email', 'status']"
    :table-filters="['username', 'email', 'phone', 'status', 'createTime']"
    :form-label-width="'120px'"
  >
    <template #extra="{ row }">
      <el-button type="primary" link @click="handleResetPassword(row)">
        重置密码
      </el-button>
    </template>
  </bi-curd>
</template>

<script setup lang="ts">
const columns = [
  {
    prop: 'username',
    label: '用户名',
    type: 'input',
    rules: [{ required: true, message: '请输入用户名', trigger: 'blur' }],
  },
  {
    prop: 'password',
    label: '密码',
    type: 'password',
    hidden: (formData) => !!formData.id,
    rules: [{ required: true, message: '请输入密码', trigger: 'blur' }],
  },
  { prop: 'email', label: '邮箱', type: 'email', search: true },
  { prop: 'phone', label: '手机号', type: 'phone' },
  {
    prop: 'status',
    label: '状态',
    type: 'select',
    search: true,
    options: [
      { label: '启用', value: 1 },
      { label: '禁用', value: 0 },
    ],
  },
  { prop: 'createTime', label: '创建时间', type: 'date' },
]

const userApi = {
  listApi: async (query) => {
    const res = await fetch('/api/user/list', { method: 'POST', body: JSON.stringify(query) })
    const data = await res.json()
    return { rows: data.list, total: data.total }
  },
  detailApi: async (id) => fetch(`/api/user/${id}`).then((r) => r.json()),
  addApi: async (data) => fetch('/api/user/add', { method: 'POST', body: JSON.stringify(data) }),
  editApi: async (data) => fetch('/api/user/edit', { method: 'POST', body: JSON.stringify(data) }),
  delApi: async (ids) => fetch('/api/user/delete', { method: 'POST', body: JSON.stringify({ ids }) }),
}

const handleResetPassword = (row) => console.log('重置密码:', row)
</script>
