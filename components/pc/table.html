BiTable 表格组件

介绍 ​

BiTable 是一个基于 Element Plus Table 组件封装的数据表格组件。它提供了更简洁的列配置方式，支持树形数据、自定义渲染、选择框等功能，适用于各种数据展示场景。

基础用法 ​

最简单的用法是通过 columns 和 data 属性来展示数据。

vue
<template>
  <bi-table :columns="columns" :data="tableData" />
</template>

<script setup lang="ts">
import { ref } from 'vue'

const columns = [
  { prop: 'name', label: '姓名' },
  { prop: 'age', label: '年龄' },
  { prop: 'address', label: '地址' }
]

const tableData = ref([
  { name: '张三', age: 28, address: '北京市朝阳区' },
  { name: '李四', age: 32, address: '上海市浦东新区' },
  { name: '王五', age: 25, address: '广州市天河区' }
])
</script>

选择框 ​

设置 type: 'selection' 来显示选择框列。

vue
<template>
  <bi-table 
    ref="tableRef" 
    :columns="columns" 
    :data="tableData" 
    @selection-change="handleSelectionChange" 
  />
</template>

<script setup lang="ts">
import { ref } from 'vue'

const tableRef = ref()

const columns = [
  { type: 'selection', width: 50 },
  { prop: 'name', label: '姓名' },
  { prop: 'age', label: '年龄' },
  { prop: 'address', label: '地址' }
]

const tableData = ref([
  { name: '张三', age: 28, address: '北京市朝阳区' },
  { name: '李四', age: 32, address: '上海市浦东新区' }
])

const handleSelectionChange = (selection: any[]) => {
  console.log('选中的行:', selection)
}
</script>

自定义列渲染 ​

使用 render 函数来自定义列内容的渲染。

vue
<template>
  <bi-table :columns="columns" :data="tableData" />
</template>

<script setup lang="ts">
import { h } from 'vue'
import { ElTag } from 'element-plus'

const columns = [
  { prop: 'name', label: '姓名' },
  { 
    prop: 'status', 
    label: '状态',
    render: ({ row, val }) => {
      const type = val === 1 ? 'success' : 'danger'
      const text = val === 1 ? '启用' : '禁用'
      return h(ElTag, { type }, () => text)
    }
  },
  {
    prop: 'action',
    label: '操作',
    type: 'slot'
  }
]

const tableData = ref([
  { name: '张三', status: 1 },
  { name: '李四', status: 0 }
])
</script>

<template>
  <bi-table :columns="columns" :data="tableData">
    <template #action="{ row }">
      <el-button type="primary" size="small" @click="handleEdit(row)">
        编辑
      </el-button>
    </template>
  </bi-table>
</template>

树形表格 ​

支持展示树形结构数据。

vue
<template>
  <bi-table 
    :columns="columns" 
    :data="tableData"
    :table-props="{ rowKey: 'id', treeProps: { children: 'children' } }"
  />
</template>

<script setup lang="ts">
const columns = [
  { prop: 'name', label: '名称' },
  { prop: 'age', label: '年龄' }
]

const tableData = ref([
  { 
    id: 1, 
    name: '张三', 
    age: 28,
    children: [
      { id: 11, name: '张三 - 子 1', age: 5 }
    ]
  },
  { id: 2, name: '李四', age: 32 }
])
</script>

带操作列的表格 ​

vue
<template>
  <bi-table :columns="columns" :data="tableData">
    <template #action="{ row }">
      <el-button type="primary" link @click="handleEdit(row)">
        编辑
      </el-button>
      <el-button type="danger" link @click="handleDelete(row)">
        删除
      </el-button>
    </template>
  </bi-table>
</template>

<script setup lang="ts">
const columns = [
  { prop: 'name', label: '姓名' },
  { prop: 'age', label: '年龄' },
  { prop: 'address', label: '地址' },
  { prop: 'action', label: '操作', type: 'slot', width: 150, fixed: 'right' }
]

const tableData = ref([
  { name: '张三', age: 28, address: '北京市朝阳区' },
  { name: '李四', age: 32, address: '上海市浦东新区' }
])

const handleEdit = (row) => {
  console.log('编辑:', row)
}

const handleDelete = (row) => {
  console.log('删除:', row)
}
</script>

自定义对齐方式 ​

vue
<template>

const columns = [

  { name: '张三', amount: 1000, status: 'success' },

])
</script>

加载状态 ​

vue
<template>
  <bi-table 
    :columns="columns" 
    :data="tableData"
    :loading="{ visible: loading }"
  />
</template>

<script setup lang="ts">
import { ref, onMounted } from 'vue'

const loading = ref(true)
const tableData = ref([])

const columns = [
  { prop: 'name', label: '姓名' },
  { prop: 'age', label: '年龄' }
]

onMounted(async () => {
  // 模拟异步加载
  setTimeout(() => {
    loading.value = false
    tableData.value = [
      { name: '张三', age: 28 },
      { name: '李四', age: 32 }
    ]
  }, 1000)
})
</script>

API ​

属性 ​

属性类型默认值说明
columnsTableColumn[]-表格列配置数组
dataRecord<string, unknown>[][]表格数据列表
adaptivebooleanfalse是否自适应高度
table-class-namestring-表格类名
loading{ visible: boolean; background?: string }-加载状态配置
option{ labelField?: string; valueField?: string }{ labelField: 'label', valueField: 'value' }选择器 label 和 value 配置
align'left' | 'right' | 'center'-内容对齐方式
table-propsRecord<string, unknown>-Element Plus Table 组件的 props

事件 ​

事件名说明回调参数
selection-change选择项变化时触发selection: Record<string, unknown>[]

插槽 ​

插槽名说明作用域参数
[prop]自定义列内容{ row, column, index }
empty空数据时显示-
append插入到表格内容末尾-
tail插入到表格末尾-

暴露的方法 ​

方法名说明
clearSelection清空选择项
getTableRef获取 Element Plus Table 实例

TableColumn 配置项 ​

属性类型说明
labelstring列标题
propstring字段名
type'selection' | 'index' | 'text' | 'slot'列类型
widthstring | number列宽度
fixed'left' | 'right'列固定位置
sortableboolean是否可排序
sortMethodFunction排序方法
align'left' | 'right' | 'center'对齐方式
renderFunction渲染函数
componentComponent自定义组件
tableColumnFuncFunction字段值处理函数
optionsTableOptionsSource选项数据
tableColumnOptionsRecord<string, unknown>el-table-column 的 props

类型定义 ​

ts
interface TableColumn {
  label?: string;
  prop?: string;
  type?: 'selection' | 'index' | 'text' | 'slot';
  tableColumnFunc?: (row: Record<string, unknown>, item: TableColumn, val: unknown) => unknown;
  width?: string | number;
  fixed?: 'left' | 'right';
  align?: 'left' | 'right' | 'center';
  sortable?: boolean;
  sortMethod?: (a: Record<string, unknown>, b: Record<string, unknown>) => number;
  render?: (options: { row: Record<string, unknown>; item: TableColumn; val: unknown; index: number }) => VNode;
  component?: Component;
  options?: TableOptionsSource;
  tableColumnOptions?: Record<string, unknown>;
}
