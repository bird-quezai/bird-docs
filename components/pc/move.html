BiMove 移动缩放组件

介绍 ​

BiMove 是一个支持拖拽移动和缩放功能的组件。它可以包装任何内容，并允许用户通过鼠标或触摸来拖拽移动内容，同时支持滚轮缩放功能。适用于需要自由移动和缩放的场景，如图片查看器、画布编辑器等。

基础用法 ​

最简单的用法是用 BiMove 包裹内容。

vue
<template>
  <bi-move>
    <div class="content">
      <img src="example.jpg" alt="示例图片" />
    </div>
  </bi-move>
</template>

<script setup lang="ts">
// 组件会自动处理拖拽和缩放
</script>

<style scoped>
.content {
  width: 100%;
  height: 100%;
}
</style>

自定义缩放比例 ​

通过 scale 属性设置初始缩放比例。

vue
<template>
  <bi-move :scale="1.5">
    <div class="content">
      <img src="example.jpg" alt="示例图片" />
    </div>
  </bi-move>
</template>

限制缩放范围 ​

通过 min-scale 和 max-scale 属性限制缩放范围。

vue
<template>
  <bi-move 
    :scale="1"
    :min-scale="0.5"
    :max-scale="5"
  >
    <div class="content">
      <img src="example.jpg" alt="示例图片" />
    </div>
  </bi-move>
</template>

监听缩放变化 ​

使用 v-model:scale 双向绑定缩放比例。

vue
<template>
  <bi-move v-model:scale="currentScale">
    <div class="content">
      <img src="example.jpg" alt="示例图片" />
    </div>
  </bi-move>
  
  <div class="controls">
    <el-button @click="zoomIn">放大</el-button>
    <el-button @click="zoomOut">缩小</el-button>
    <span>当前缩放：{{ currentScale }}x</span>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const currentScale = ref(1)

const zoomIn = () => {
  currentScale.value = Math.min(currentScale.value + 0.1, 5)
}

const zoomOut = () => {
  currentScale.value = Math.max(currentScale.value - 0.1, 0.5)
}
</script>

设置初始位置 ​

通过 x 和 y 属性设置初始位置。

vue
<template>
  <bi-move :x="100" :y="50">
    <div class="content">
      <img src="example.jpg" alt="示例图片" />
    </div>
  </bi-move>
</template>

图片查看器示例 ​

vue
<template>
  <div class="image-viewer">
    <bi-move 
      v-model:scale="scale"
      :min-scale="0.1"
      :max-scale="10"
    >
      <img :src="imageUrl" alt="可缩放图片" />
    </bi-move>
    
    <div class="toolbar">
      <el-button @click="scale = 1">实际大小</el-button>
      <el-button @click="scale = scale + 0.5">放大</el-button>
      <el-button @click="scale = scale - 0.5">缩小</el-button>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const scale = ref(1)
const imageUrl = ref('example.jpg')
</script>

<style scoped>
.image-viewer {
  width: 100%;
  height: 500px;
  border: 1px solid #ddd;
  position: relative;
}

.toolbar {
  position: absolute;
  bottom: 10px;
  left: 50%;
  transform: translateX(-50%);
  display: flex;
  gap: 10px;
}
</style>

画布编辑器示例 ​

vue
<template>
  <bi-move 
    v-model:scale="canvasScale"
    :min-scale="0.1"
    :max-scale="3"
  >
    <div class="canvas" :style="{ transform: `scale(${canvasScale})` }">
      <!-- 画布内容 -->
      <div 
        v-for="item in items" 
        :key="item.id"
        class="canvas-item"
        :style="{ 
          left: item.x + 'px', 
          top: item.y + 'px' 
        }"
      >
        {{ item.content }}
      </div>
    </div>
  </bi-move>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const canvasScale = ref(1)

const items = ref([
  { id: 1, x: 100, y: 100, content: '元素 1' },
  { id: 2, x: 200, y: 150, content: '元素 2' }
])
</script>

<style scoped>
.canvas {
  position: relative;
  width: 1000px;
  height: 800px;
  background: #f5f5f5;
  transform-origin: 0 0;
}

.canvas-item {
  position: absolute;
  padding: 10px;
  background: #409EFF;
  color: white;
  border-radius: 4px;
  cursor: move;
}
</style>

API ​

属性 ​

属性类型默认值说明
scalenumber1缩放比例
min-scalenumber0.01最小缩放比例
max-scalenumber10最大缩放比例
xnumber0初始 X 轴位置
ynumber0初始 Y 轴位置
child-class-namestring-子元素的类名

事件 ​

事件名说明回调参数
update:scale缩放比例变化时触发scale: number

插槽 ​

插槽名说明
default默认插槽，用于放置可移动和缩放的内容

类型定义 ​

ts
interface BiMoveProps {
  /** 缩放比例 */
  scale?: number;
  /** 最小缩放比例 */
  minScale?: number;
  /** 最大缩放比例 */
  maxScale?: number;
  /** 初始 X 轴位置 */
  x?: number;
  /** 初始 Y 轴位置 */
  y?: number;
  /** 子元素的类名 */
  childClassName?: string;
}

注意事项 ​

  1. 组件会自动处理鼠标和触摸事件的拖拽移动
  2. 缩放功能通过鼠标滚轮实现
  3. 缩放比例变化会有防抖处理（100ms）
  4. 组件会限制内容在父容器范围内移动
  5. 最小缩放比例不能小于 0.01
  6. 最大缩放比例不能超过 10

常见问题 ​

如何重置缩放和位置？ ​

vue
<template>
  <bi-move ref="moveRef">
    <div class="content">内容</div>
  </bi-move>
  <el-button @click="reset">重置</el-button>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const moveRef = ref()
const scale = ref(1)

const reset = () => {
  scale.value = 1
  // 重置位置需要访问内部实例
}
</script>

如何禁用拖拽但保留缩放？ ​

目前组件没有提供禁用拖拽的属性，可以通过 CSS 实现：

vue
<template>
  <bi-move>
    <div class="content" :class="{ 'disable-drag': disableDrag }">
      内容
    </div>
  </bi-move>
</template>

<style scoped>
.disable-drag {
  pointer-events: none;
}
</style>
