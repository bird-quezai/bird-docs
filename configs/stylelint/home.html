@bird/stylelint-config

Volcano 的 Stylelint 配置预设，基于 stylelint-config-ali，支持 HTML、Vue、CSS、SCSS、LESS 等文件格式。

  • 基于 stylelint-config-ali 的规则集
  • 支持 HTML 和 Vue 文件中的样式检查（通过 postcss-html）
  • 自动对 CSS 属性进行排序（基于渲染布局逻辑）
  • 支持 ::deep 等 Vue 特有的伪类选择器

安装 ​

bash
pnpm i -D stylelint @bird/stylelint-config

使用方法 ​

创建配置文件 ​

在项目根目录创建 stylelint.config.js 文件：

js
export default {
  extends: ['@bird/stylelint-config'],
};

在 package.json 中添加命令 ​

json
{
  "scripts": {
    "lint:style": "stylelint \"**/*.{css,scss,less,vue,html}\" --fix"
  }
}

VSCode 中的 Stylelint 设置 ​

在 .vscode/settings.json 中添加：

json
{
  "editor.codeActionsOnSave": {
    "source.fixAll.stylelint": "explicit"
  },
  "stylelint.validate": [
    "css",
    "scss",
    "less",
    "vue",
    "html"
  ]
}

配置说明 ​

默认配置 ​

  • extends: stylelint-config-ali - 继承阿里团队的 stylelint 配置
  • plugins: stylelint-order - CSS 属性排序插件
  • customSyntax: postcss-html - 支持解析 HTML 和 Vue 文件中的样式
  • defaultSeverity: error - 默认错误级别

自定义规则 ​

CSS 属性排序

配置了基于渲染布局逻辑的 CSS 属性排序规则，顺序如下：

  1. 影响文档流的属性：position、display、flex、grid 等
  2. 盒模型属性：width、height、margin、padding、border 等
  3. 外观属性：background、color、box-shadow、outline 等
  4. 文字属性：font、text-align、line-height 等
  5. 其他属性：opacity、transform、animation、transition 等

Vue 支持

  • 支持 ::deep 伪类选择器（Vue 的深度选择器）
  • 自动识别 Vue 单文件组件中的 <style> 标签

覆盖配置 ​

如果需要覆盖默认配置，可以这样使用：

js
import stylelintConfig from '@bird/stylelint-config';

export default {
  ...stylelintConfig,
  rules: {
    ...stylelintConfig.rules,
    // 覆盖或添加自定义规则
    'your-custom-rule': true,
  },
};

特性 ​

  • ✅ 支持 CSS、SCSS、LESS
  • ✅ 支持 HTML 和 Vue 文件中的样式检查
  • ✅ 自动 CSS 属性排序
  • ✅ 基于 stylelint-config-ali 的成熟规则集
  • ✅ 支持 Vue 深度选择器语法
